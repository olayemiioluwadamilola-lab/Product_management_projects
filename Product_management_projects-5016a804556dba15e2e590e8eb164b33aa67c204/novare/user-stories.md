# User Stories & Backlog: Novare

## Epic 1: Custom Co-Ord Configurator

### User Story 1.1: Mix-and-Match Color Selection
* **As a** customer purchasing a streetwear set,  
* **I want to** choose different colors for my top and bottom garments independently,  
* **So that** I can create a personalized two-piece outfit that matches my style.  
* **Acceptance Criteria:**
  * Selecting "Deep Black" for the top and "Slate Grey" for the bottom updates both image tiles immediately.
  * The active color swatch must display a visible checkmark indicating selection.

---

### User Story 1.2: Signature Logo Accent Selection
* **As a** luxury apparel buyer,  
* **I want to** pick a custom metallic finish for the Novare logo,  
* **So that** my set features a unique signature detail.  
* **Acceptance Criteria:**
  * Users can toggle between Gold, White, and Metallic Silver.
  * The selected accent is reflected in the configuration summary card.

---

## Epic 2: Sizing & Checkout

### User Story 2.1: Dual Garment Sizing
* **As a** shopper with different sizing needs for tops and bottoms,  
* **I want to** select my roundneck size and jogger size on the same screen,  
* **So that** I don't need to add two separate items to my cart manually.  
* **Acceptance Criteria:**
  * Top and bottom size grids operate independently.
  * Attempting to add to cart without selecting both sizes prompts a required selection state.
