## 👟 Project 1: Nike E-Commerce Landing Page

A sleek, high-conversion web interface designed for an e-commerce storefront. The design focuses on product spotlighting, clean typography, and seamless colorway transitions.

### Key Features
* **Dynamic Product Showcase:** A centralized, high-impact product display featuring the Air Jordan 1 Mid Men's Shoe.
* **Component-Driven Colorways:** UI seamlessly adapts to different product variants (Orange, Blue, and Brown) to maintain aesthetic consistency.
* **Minimalist Navigation:** Clean top navigation bar (Home, About Us, Trending, Shop, Sales) and clear secondary actions (Search, Favorites, Cart).
* **Call to Action (CTA):** Prominent "Add to Bag" button paired with pricing and an interactive "Play Trailer" element.

## 🌸 Project 2: SheTrack — Menstrual Cycle Tracker

A mobile application interface designed to empower women by helping them track their menstrual cycles, monitor health metrics, and predict biological windows. The design uses a soft, approachable color palette with intuitive navigation.

### Key Features
* **Welcoming Onboarding:** An aesthetic, editorial-style splash screen ("Welcome to SheTrack") that establishes a calming brand identity.
* **Streamlined Authentication:** A clean, accessible login screen requiring minimal user effort.
* **Interactive Calendar View:** A visual tracker using pin icons to denote cycle days, providing immediate, at-a-glance information.
* **Health Insights:** Clear status indicators showing days until the next period and current pregnancy probability (e.g., "low chance of getting pregnant"), allowing users to log their periods effortlessly.
