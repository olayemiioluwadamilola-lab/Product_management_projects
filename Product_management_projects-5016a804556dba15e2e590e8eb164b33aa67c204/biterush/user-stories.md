# User Stories & Backlog: BiteRush

## Epic 1: Batch Ordering

### User Story 1.1: Joining a Batch Window
* **As a** hostel student on a tight budget,  
* **I want to** join an active batch delivery window for my specific hostel block,  
* **So that** I can split the total delivery fee with other students in my building.  
* **Acceptance Criteria:**
  * Given an active batch window for "Hostel B", when I add items to my cart, then the delivery fee must automatically adjust to the ₦200 batch rate.
  * The checkout screen must show a live countdown timer showing when the batch window closes.

## Epic 2: CraveCash Wallet

### User Story 2.1: Wallet Checkout
* **As a** regular user,  
* **I want to** pay directly from my pre-funded CraveCash wallet,  
* **So that** I can complete my order without bank transfer delays.  
* **Acceptance Criteria:**
  * When selecting CraveCash at payment, system checks for sufficient balance.
  * If balance is sufficient, order confirmation must execute in 2 taps or less.
