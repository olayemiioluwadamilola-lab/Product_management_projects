# UI/UX & Prototyping Showcase — Figma Workspace

Welcome to my central Figma design and prototyping repository. As a Product Manager with a UI/UX background, I utilize Figma to move rapidly from low-fidelity user flows and wireframes to interactive, component-driven prototypes.

---

## 🎨 Featured Figma Projects

### 1. Jumia App — Cart Selective Checkout Feature
* **Overview:** A UX optimization concept for the Jumia e-commerce app allowing users to selectively check out specific cart items without removing others.
* **Key Techniques:** Auto Layout 5.0, Component Variants, Interactive States, Cart Logic Flow.
* **Problem Solved:** Reduces cart abandonment caused by bulk item totals and eliminates manual item deletion.

### 2. BiteRush — Campus Food Delivery Design System
* **Overview:** Full interface and flow design for a hyper-local campus food delivery platform tailored to Nigerian university hostels.
* **Key Techniques:** Design Tokens, Responsive Layouts, Mobile UI Wireframing, User Flow Architecture.
* **Features Visualized:** Hostel Batching Timer, CraveCash Wallet, and Common-Room Landmark Selectors.

### 3. Kicks Spot — E-Commerce & Fulfillment Tracker
* **Overview:** High-contrast, dark-mode storefront designed to elevate sneaker retail discovery and post-purchase order tracking.
* **Key Techniques:** Interactive Component Prototyping, Visual Hierarchy, Micro-interactions.
* **Features Visualized:** Real-time fulfillment status board, product variant swatches, dynamic cart drawer.
