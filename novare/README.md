# Case Study: Novare — Custom Co-Ord Streetwear E-Commerce

## 📌 Executive Summary
Novare is a bespoke luxury e-commerce experience designed for custom co-ord apparel. It features an interactive, real-time 2-piece set builder where shoppers can configure top and bottom garment colors, select signature logo accents, and customize sizing before purchasing made-to-order streetwear.

---

## 🎯 Problem Statement
* **Static E-Commerce Limitations:** Standard apparel stores force buyers to purchase set colors, limiting personal style and mix-and-match preferences.
* **Low Visual Confidence:** Customers purchasing customizable clothing often struggle to visualize how different top/bottom color combinations and accents look together.
* **Complex Sizing Drops:** Ordering non-matching top and bottom sizes usually requires navigating two separate product pages, causing friction and drop-offs during checkout.

---

## 💡 Solution & Key Features
* **Interactive Garment Configurator:** Real-time top and bottom fabric split preview allowing custom pairings (Deep Black, Soft Obsidian, Off-White, Olive, Slate Grey, Charcoal).
* **Signature Accent Selector:** Choice of luxury metallic logo accents (Gold, White, Metallic Silver) rendered directly on the garment preview.
* **Unified 2-Piece Sizing:** Single-page interface to select independent top and bottom sizes (S to 3XL) with dynamic price calculation ($178 set total).
* **Luxury Dark-Mode Aesthetic:** Sleek typography and high-contrast UI tailored specifically for luxury streetwear branding.
