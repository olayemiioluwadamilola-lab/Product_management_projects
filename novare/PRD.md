# Product Requirement Document (PRD): Novare Custom Co-Ord Atelier

## 1. Document Overview
* **Product Name:** Novare
* **Author:** Olayemi Olasunkanmi (Product Manager)
* **Status:** MVP Published

---

## 2. Target Personas
* **Primary:** Fashion-conscious young adults and streetwear enthusiasts seeking customized, high-end apparel.
* **Secondary:** Gift buyers and couples looking for matching or complementary co-ord sets.

---

## 3. Core Epics & Functional Requirements

### Epic 1: Interactive Set Builder
* **FR-1.1:** System MUST render a dual-panel preview updating top and bottom garment imagery in real time based on user selection.
* **FR-1.2:** System MUST allow independent color selection for roundneck tops and jogger bottoms across 6 signature fabric colors.
* **FR-1.3:** System MUST offer 3 logo accent variations (Gold, White, Metallic Silver) and apply the selection across both garments.

### Epic 2: Custom Sizing & Cart Execution
* **FR-2.1:** Interface MUST provide separate size selectors (S, M, L, XL, 2XL, 3XL) for top and bottom garments within a single view.
* **FR-2.2:** "Build Your Set" CTA MUST update dynamically to reflect the final configured set and total pricing ($178).

---

## 4. Key Performance Indicators (KPIs)
* **Conversion Rate:** Percentage of users who complete a custom set build and proceed to checkout.
* **Configurator Engagement:** Average number of color/accent swaps performed per user session.
* **Cart Abandonment:** Reduction in drop-offs compared to traditional multi-page apparel shopping flows.
